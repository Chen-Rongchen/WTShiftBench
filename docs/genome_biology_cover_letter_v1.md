# Genome Biology cover letter v1

Dear Editors,

We are pleased to submit our Research article, "A truth-anchored framework and resource for evaluating transcriptomic perturbation models against cancer dependency endpoints", for consideration in Genome Biology.

Perturbation transcriptome models are increasingly used to reason about gene function, cellular response and disease-relevant biology. However, these models are commonly evaluated by expression reconstruction rather than by recovery of transcriptomic structures linked to downstream phenotypes. This leaves an important gap for functional genomics: a model may predict expression shifts without recovering the components of a perturbation response that align with fitness or dependency.

In this study, we develop a truth-anchored framework and resource that aligns perturbation transcriptomic shifts with cancer dependency endpoints before model comparison. Using HCC38 and HCC1143 as primary contexts, we define a frozen CRISPR fitness bridge, decompose it into target-level anchors and axis-level evidence, audit covariate and endpoint boundaries, and then evaluate current perturbation model entrants against the predefined architecture. The benchmark decomposes model behavior across backbone recovery, shift-excess identification and structure-versus-context separation, revealing a backbone-vs-separation trade-off rather than a single leaderboard result. The shared-mean reference is strongest for canonical backbone recovery, whereas GEARS shows stronger structure-versus-context separation. Foundation-model and embedding-based linear controls do not close this backbone gap. K562 temporal and RNAi analyses provide bounded external and endpoint sensitivity rather than unrestricted replication.

We believe this manuscript fits Genome Biology because it addresses a functional-genomics problem from a genomic and post-genomic perspective, combines single-cell perturbation data with cancer dependency endpoints, and provides a reproducible benchmark resource for model evaluation. The work is not framed as a new software-only model or a target-discovery claim. Instead, it provides a transparent framework for determining which biological components of a phenotype-relevant perturbation architecture are recovered, missed or only partially supported by current models.
