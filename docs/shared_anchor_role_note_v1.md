# Shared anchor role note v1

## 状态

更新日期：2026-04-20。

用途：明确 shared anchors 在 Genome Biology 投稿叙事中的角色，避免把它们写得过重或过轻。

## 结论

Shared anchors 重要，但不是全文主卖点。

它们应该承载的是：

- HCC truth bridge 的 target-level content example。
- 证明 frozen bridge object 不是纯 global scalar correlation，而有可检查的 target-level structure。
- 支撑 claim governance 的价值：同一个对象可以被识别、分层、降权和限制措辞。
- 连接 Fig. 1 truth object 与 Fig. 2 evidence tiering 的主线。

它们不应该承载的是：

- broad cancer dependency mechanism。
- cross-context content-level replication。
- fully deconfounded causal target claim。
- biological discovery headline。
- model recovery 主结论。

## 当前证据定位

严格 shared anchor set：

- `PFDN5`
- `PMF1`
- `PRPF6`
- `ZNF131`

当前 tier：

- `PFDN5`：primary but qualified。
- `PMF1 / PRPF6 / ZNF131`：supporting only。

Cutoff sensitivity extension：

- 放宽到 2/3 cutoff pairs：7 个 shared objects。
- 放宽到 1/3 cutoff pairs：9 个 shared objects。
- 新增对象只作为 robustness，不升级 primary tier。

## 推荐写法

可以写：

- Shared anchors support the existence of a structured HCC perturbation-fitness bridge.
- Shared anchors provide target-level content examples within a frozen benchmark truth object.
- PFDN5 remains primary but qualified; PMF1, PRPF6 and ZNF131 remain supporting only.
- Anchor tiering illustrates claim governance rather than causal target discovery.

不建议写：

- Shared anchors validate the bridge.
- Shared anchors prove dependency mechanisms.
- Shared anchors replicate across cancer contexts.
- PFDN5 is a primary biological discovery.
- The shared anchor set establishes broadly generalizable dependency biology.

## 对主文结构的作用

Shared anchors 的最佳位置是 Fig. 2 / Results 第二段：

- Fig. 1：定义 benchmark truth object。
- Fig. 2：展示这个 object 有 target-level content，但 content 被严格 tiered。
- Fig. 3-4：模型恢复的是 architecture，不是 anchor discovery。
- Fig. 5-6：axis / covariate / endpoint 继续限制 content claim。

因此，shared anchors 是文章的 evidence-governance demonstration，不是主 biological payload。
