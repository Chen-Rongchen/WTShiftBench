# WTShiftBench v1.1.0

This release provides the code, Pixi environments, governed registries,
editable SVG panels and per-panel source data for the current WTShiftBench
resource architecture.

- Main Figure 1-4.
- Extended Data Figure 1-6.

## Major updates

- Reframed model-output collapse as axis-free output homogenization.
- Added target-identity and output-geometry diagnostics.
- Added finite-budget sensitivity for scGen, GEARS, CPA and CellOT.
- Consolidated external bridge evidence around detectability and attenuation.
- Consolidated response-program analyses around annotation and robustness,
  without pathway-mechanism claims.
- Updated active registries, source-data manifests and artifact hashes.
- Standardized environment management on Pixi.

## Public bundle policy

The release contains source code, Pixi metadata, resource registries, editable
panel-level SVGs, per-panel source data and required lightweight cached tables.
Composite figures, manuscript files, raster/PDF exports, raw single-cell
objects and model-training intermediates are intentionally excluded.

## Claim boundary

WTShiftBench audits endpoint-aligned recovery, target-identity preservation,
axis-free output homogenization and bridge-form boundary behavior. It does not
claim direct DepMap prediction, causal pathway mechanisms, universal model
rankings or broad cross-dataset model generalization.
